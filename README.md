# DHBT

Дипломный Android-проект для трекинга привычек, управления задачами и личной продуктивности.

## Что реализовано
- Управление задачами: категории, теги, подзадачи, повторения и приоритеты
- Матрица Эйзенхауэра для распределения задач по важности и срочности
- Трекер привычек с настраиваемой периодичностью и историей выполнения
- Таймер Помодоро с настройками сессий и перерывов
- Дашборд и статистика с графиками
- Локальные уведомления с быстрыми действиями и восстановлением после перезагрузки (`WorkManager`, `BootReceiver`)
- Настройки темы, смены языка, онбординг и экспорт данных

## Стек
- **Язык:** Kotlin
- **UI:** Jetpack Compose, Material 3, Navigation Compose, MPAndroidChart, Lottie, Coil
- **Архитектура:** Clean Architecture, MVVM, StateFlow, Coroutines
- **DI:** Dagger Hilt
- **База данных и хранилище:** Room, DataStore Preferences
- **Фоновая работа:** WorkManager
- **Дополнительно:** OpenCSV, Apache POI, Timber, JUnit4, Mockito
